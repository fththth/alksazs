# القزاز لخدمات الحاسبات

محل تجميعة حاسبات بصفحتين: صفحة للزبون يختار فيها القطع ويشوف السعر الإجمالي، ولوحة تحكم لإدارة المخزون.

## الصفحات

- `/` تجميعة الزبون: معالج، مذربود، رامات، كرت شاشة، تخزين، كولر، وكيس. يحسب السعر ويظهر تعارض التوافق (السوكت، نوع الرام، حجم الكيس).
- `/dashboard` لوحة التحكم: إضافة وتعديل ومسح القطع، تعديل السعر والمخزون، ورقم واتساب الطلب.

الأسعار بالدينار العراقي وتظهر بـ IQD مع أرقام إنجليزية. الكتالوج يُحفظ محلياً في `data/catalog.json`.

## التشغيل

```bash
npm install
npm run dev
```

الموقع يفتح على [http://127.0.0.1:43123](http://127.0.0.1:43123).

للبناء للإنتاج:

```bash
npm run build
npm start
```

## ملاحظة

ماكو قاعدة بيانات خارجية. التعديلات تتخزن بملف JSON على الجهاز اللي يشغّل السيرفر، وتقدر ترجع الكتالوج التجريبي من لوحة التحكم.
